🔗 5 Key "Glue" Concepts Beginners Must Know

        

          

            
CORS

            
Browsers block port 3000 (HTML) from calling port 8000 (FastAPI) by default. Adding CORSMiddleware in main.py grants permission.

          

          

            
JS fetch()

            
Built-in browser function that calls FastAPI URLs silently in the background (GET/POST) and updates HTML cards with zero page reload.

          

          

            
ipconfig IPv4

            
ESP32 cannot reach "localhost". Run ipconfig on Windows to find your laptop's Wi-Fi IP (e.g., 192.168.1.100) for the ESP32 URL.

          

          

            
--host 0.0.0.0

            
Running Uvicorn with --host 0.0.0.0 exposes FastAPI across your Wi-Fi hotspot so both the ESP32 and evaluators' phones can connect.

          

          

            
JSON

            
A universal text dictionary like {"U1": true, "R1": false} understood natively by ArduinoJson, Python FastAPI, MongoDB, and JS.

Golden Rule: Common Ground (Shared Across Everything!)

            

              Power your 4 IR obstacle sensors and the 16×2 I2C LCD from an external 5V DC power supply connected to the breadboard + / - rails. You MUST run a jumper wire from the breadboard's negative (-) rail to a GND pin on the ESP32 so ESP32, LCD, sensors, and all 8 LEDs share one Common Ground. Without it, IR readings will glitch!

🏗️ Sunboard / Cardboard Model Tips

            
    
              
  • Base Size: Use a sturdy 30 × 30 cm foam/sunboard sheet divided into two clearly painted zones: Underground (B1: U1, U2) and Rooftop (R1: R1, R2).
    • 
              
  • Side Dividers: Add short vertical dividers between neighboring bays so infrared reflections from a car in U1 never accidentally trip U2.
    • 
              
  • Bumper Height & Tuning: Mount each LM393 sensor on the rear wall facing forward at toy-car height. Twist the blue screw until its onboard green indicator LED lights up only when a car sits inside that bay.
    • 
              
  • Hide the Wires: Poke tiny holes above each bay for the Green/Red LEDs and route jumper wires cleanly underneath to the ESP32 + 16×2 LCD mounted at the entrance gate.
